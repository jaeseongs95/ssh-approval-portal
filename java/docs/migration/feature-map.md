## 5. 원자료 범위 밖이지만 3.0 전환에 영향이 있는 것(행 없음, 별도 목록 필요)

원자료가 제외한 파일이지만 3.0 구현 담당이 알아야 하는 것이다. 이 표에는 행이 없으므로 「빠진 파일 0」 판정은 248행 범위에서만 성립한다. 메인이 별도 목록(원자료 2판)을 만들지 판정해야 한다.

- `web/app.js`: 관리 UI 진입점(esbuild가 `web/src/**`를 IIFE로 묶음, `ui/build.mjs`). 계획은 ES 모듈 직접 서빙이므로 진입 모듈이 필요하다. 내용은 읽지 않았다.
- `package.json`, `package-lock.json`, `ui/package-lock.json`(표에 있음): Node 의존 목록. 삭제 대상이다. 의존 `jose`(JWT)는 Spring Security `JwtDecoder`가, `@modelcontextprotocol/sdk`는 Spring AI MCP가 대체한다.
- `vendor/ssh-mcp-2.18.0.tgz`: vendor 소스. 연결 레지스트리·프로필 로더·SFTP·`policy/classifier.js`·`guard/redactor.js`의 행동 규칙을 portal-ssh와 portal-domain(`CommandClassifier`, `Redactor`)으로 옮겨야 한다. 규칙 목록은 이 표에 없다. 「2단계 선행 조사」(메인 판정 C5): vendor ssh-mcp-2.18.0의 분류기·redactor 규칙 목록(그리고 프로필 TOML 허용 키·기본값, `SSH_MCP_*` 의미)을 먼저 조사해 portal-domain 이식의 입력으로 삼는다. `test-server-mode.mjs`의 설정 키 이름 확인(C4)은 2.x 원본으로 끝냈다(6절 행 341).
- `vendor/freerdp-input-v1-linux-x64.tgz`: prebuilt xfreerdp3 묶음(SHA256은 `prepare-freerdp-input.py`에 고정). Gradle `verifyFreerdpBundle`의 입력이다.
- `test/**`: 회귀 사례표(`regression-cases.part-a/b.md`)가 담당. Jev 코퍼스(`test/fixtures/*`)는 Q6(A안)으로 이를 쓰던 연구 도구가 삭제되므로 회귀 사례표가 사용 여부를 판정한다.
- `docs/**`, `README*`: 영·한 쌍 문서 규칙(7단계 문서 담당).
- `THIRD_PARTY_NOTICES.json`, `release-manifest.json`, `web/dist/**`, `ui/dist/**`: 생성물. 3.0은 Gradle 작업이 만든다(`notices.mjs`·`verify.mjs` 행 참조).
- 실행 시 생성되는 파일: `completion-watch.json`(클라이언트 설치기가 작성), 클라이언트 `client-manifest.json`. 3.0 클라이언트 설치기도 같은 역할의 파일을 만든다.
