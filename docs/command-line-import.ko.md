# 명령줄에서 사전 허용 명령 이름 가져오기

관리자 설정의 명령 관리에서 **명령줄 붙여넣기**를 누르고 한 줄의 명령을 입력합니다. **명령 이름 추출** 후 필요한 이름을 직접 선택하고 **선택한 이름을 초안에 추가**합니다. 기존의 위험도 검토와 OK 확인을 거쳐 저장해야 적용됩니다. 추출한 이름은 처음에 모두 선택 해제되어 있습니다.

등록 단위는 명령 이름입니다. 등록하면 그 이름의 다른 옵션·인자도 기존 사전 허용 정책의 적용을 받습니다. 붙여넣은 한 줄만 허용하는 기능이 아닙니다. sudo 권한, 모델 사용 여부, 사용자가 정한 점수 기준은 바꾸지 않습니다. 차단 목록에 있는 이름과 이미 초안에 있는 이름은 가져오기에서 제외합니다.

서버의 기존 명령 이름 분석기를 브라우저에서도 사용합니다. 파이프·리다이렉션·지원되는 인용과 리터럴 중첩 명령을 같은 규칙으로 해석합니다. 이름 추출은 명령 실행이나 인자의 안전성 평가가 아닙니다. Python 등의 실행기에 전달한 코드를 새로운 사전 허용 규칙으로 해석하지 않습니다. 동적·지원하지 않는 구문이나 불완전한 입력에서는 일부 이름만 등록하지 않고 전체 추출을 거절합니다. 여러 줄 입력은 지원하지 않습니다.

입력은 UTF-8 기준 32KiB(32,768바이트), 명령 이름은 80자, 기존 초안을 포함한 이름 목록은 128개 제한을 따릅니다. 선택한 묶음이 목록 제한을 넘으면 묶음 전체를 추가하지 않습니다. 원문이 바뀌면 이전 후보와 선택을 지웁니다.

승인 이력의 일반 명령에는 **이력의 명령 이름 등록** 버튼이 있습니다. 현재 대상 ID·연결 revision·프로필이 이력과 모두 일치할 때만 최신 설정에 원문을 채웁니다. 자동 선택하거나 저장하지 않습니다. 연결 정보가 없는 옛 이력은 버튼을 사용할 수 없고, 대기·실행 중인 요청, 파일 전송, 제출 소스 실행 이력에는 등록 버튼을 제공하지 않습니다.

직접 붙여넣은 원문은 페이지 메모리에서만 분석하며 추출·선택 과정에서 API나 모델에 보내지 않습니다. 이력 버튼은 최신 연결 정보를 읽기 위해 설정 API를 조회합니다. 이때 원문을 다시 전송하지 않습니다. 저장 요청에는 기존 정책의 명령 이름 목록만 포함합니다. 대상·페이지 변경, 설정 재조회, 저장 완료, 로그아웃 시 가져오기 입력을 지우며, 늦게 도착한 이력 조회로 다시 채우지 않습니다. 기존 실행 이력에 저장된 원문 자체를 삭제하는 기능은 아닙니다.

검사는 합성 데이터와 loopback 서버에서 수행합니다. Playwright의 Chromium·Firefox·WebKit과 화면 너비 320·390·768·1024·1440, 한국어·영어를 대상으로 저장 절차·키보드·후보 스크롤·명령 그리드 스크롤을 확인합니다. WebKit 검사는 실제 Safari나 모바일 실기기 검사를 대신하지 않습니다. 배포 여부와 실제 실행 결과는 별도 배포 기록으로 확인해야 합니다.
