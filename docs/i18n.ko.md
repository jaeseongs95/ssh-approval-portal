# 관리자 화면과 카드의 다국어 처리

관리자 화면과 승인 카드는 `web/src/locale.js`의 공통 처리와 기존 한국어 메시지 키를 사용한다. 한국어 원문을 키로 쓴 사실만으로 번역 결함으로 판정하지 않는다. `web/src/i18n.js`, `web/src/ui-text.js`, `ui/src/i18n.js`, 실행 한도 패널의 `web/src/capacity.js`가 실제 한국어·영어 카탈로그를 제공한다. 정책·명령·출력·사용자 입력은 번역 대상으로 바꾸지 않는다.

`Intl.getCanonicalLocales`로 BCP 47 언어 태그를 정규화한다. 잘못된 값은 `en-US`를 사용하고, `ko` 계열은 한국어 메시지, 그 밖의 언어는 영어 메시지를 사용한다. `fr-FR`처럼 메시지 카탈로그가 없는 유효한 태그도 숫자와 날짜 표시에서는 해당 지역 형식을 보존한다. 브라우저별 저장 언어 선택과 기존 페이지 이동·초안 보존 흐름은 유지한다.

숫자와 날짜는 `Intl.NumberFormat`과 `Intl.DateTimeFormat`으로 표시한다. 실행 한도 패널은 숫자 조각을 이어 붙이지 않고 `{queued}`, `{running}` 같은 이름 있는 자리표시자가 포함된 문장 전체를 번역한다. 카탈로그를 만들 때 양쪽 언어의 키, 메시지 문법, 자리표시자 일치를 검사한다. 알 수 없는 키는 영어 카탈로그를 거친 뒤 원문으로 돌아간다.

전역 실행 대기·동시 실행 한도는 중계기 화면에서, 선택 서버의 한도는 서버 화면에서 편집한다. 서버의 빈 입력은 API에 `null`을 보내 전역값을 상속한다. 적용된 실효 한도와 마지막 조회 시점의 대기·실행 현황을 함께 표시한다. 설치 기본값은 가용 CPU 수의 10배와 CPU 수이며, 한도 축소는 실행 중인 작업을 강제 종료하지 않는다. 저장은 리비전을 포함한 POST 한 번으로 보내며, 응답을 잃으면 다시 저장하기 전에 GET으로 실제 값을 확인해야 한다. 초안은 페이지 메모리에만 남는다.

서버 데스크톱 뷰어는 별도 `web/src/desktop.js`에 있다. 선택 서버의 현재 revision을 확인한 뒤 실제 OS 화면 연결을 요청하며, PNG 화면과 프레임·좌표계·입력 순번·요청 키를 함께 유지한다. CSS 표시 크기와 물리 화면 크기의 비율로 좌표를 변환하고 기기 픽셀 비율을 다시 곱하지 않는다. 키와 클릭은 누른 뒤 해제하는 한 묶음으로 전달한다. 입력 응답을 잃으면 자동으로 재입력하지 않고 화면을 다시 관측한다. 기본 뷰어는 클릭·단축키·텍스트 전송을 지원하며 드래그는 지원하지 않는다. Tab 키는 브라우저 초점 이동을 보존한다. 연결이 열려 있으면 서버 선택과 언어 새로고침을 잠그며, 다른 페이지로 이동하거나 앱에서 로그아웃할 때 연결 닫기를 요청한다. 서버 계정 로그아웃은 하지 않는다.

검증 명령은 `node --test test/i18n.test.mjs test/capacity-ui.test.mjs test/capacity-ui-desktop.test.mjs`다. 카탈로그 키·자리표시자·문법·언어 폴백·지역 형식, 실제 번역 호출의 누락, 한도 입력·상속·리비전·초안 보존·응답 손실 후 중복 저장 방지, 데스크톱 좌표·키 입력·로그아웃 전 연결 닫기를 검사한다. 제품 시험은 승인된 테스트 서버 또는 CI에서 실행한다. 이 문서는 시험 통과를 주장하지 않으며 실제 실행 결과는 해당 실행 근거로 판단한다.
