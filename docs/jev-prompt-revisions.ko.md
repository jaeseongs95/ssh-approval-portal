# Jev 실행 판정 프롬프트 리비전

저장된 `ssh-command-risk-v4`는 기존 3개 위험 라벨과 사용자 확률 기준의 정책 계약이다. 본문 변경은 `AUTOMATION_PROMPT_REVISION`과 `AUTOMATION_PROMPT_SHA256`로 구분한다. 실제 평가 결정의 `evaluation`에 두 값이 함께 저장되므로 같은 계약을 사용한 과거 문구와 새 문구를 구별할 수 있다. 기존 기록은 재작성하지 않는다.

이번 본문 `ssh-command-risk-v4-evidence-r1`은 조건부 합성 사례 49개를 비교한 후보와 정확히 일치한다. 정확 라벨 결과는 46/48에서 47/48로 바뀌었으나, 검증 집합 16개는 양쪽 16/16 동률이어서 사전 개선 수용 기준은 통과하지 못했다. 사용자가 그 결과를 확인한 뒤 우선 적용을 선택했다. 이 선택을 모델 품질 검증 통과나 확률 보정 완료로 표현하지 않는다.

저장 정책·모델·숫자 기준값·승인/거부/외부 전송 gate·폴백 규칙은 변경하지 않는다. 라우팅 분류명과 미검증 목록의 제거는 별도 탐색 진단이므로 이번 적용에 포함하지 않는다. 고정 질문과 명령·소스·AI 목적 주장은 서로 다른 신뢰 경계로 유지한다.

이 리비전은 실행 자동승인 평가 질문에 적용된다. 사전 명령 이름 등록 검토와 별도 관찰용 질문을 동일하게 교체했다고 주장하지 않는다.

실제 모델 호출 후 응답 오류·형식 오류·타임아웃으로 수동 검토에 남는 경우도 해당 프롬프트 식별자를 기록한다. 모델을 호출하지 않은 사전 차단에는 호출 이력을 만들지 않는다. 과거 실험 생성기는 별도의 고정 원본을 사용하므로 운영 질문 변경이 과거 wire를 바꾸지 않는다.
