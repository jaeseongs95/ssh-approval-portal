# 관리자 작업 공간

관리 메뉴는 작업, 처리 이력, 서버, 중계기, 화면 설정으로 나뉜다. 기본 화면은 모든 서버의 승인 대기와 처리 중 요청이다.

## 작업과 요청 상세

조회 서버는 목록을 좁히는 조건이다. 실제 승인 대상은 각 요청에 기록된 서버와 요청 식별자다. 같은 명령이 여러 서버에서 올라와도 요청 상세에서 대상을 확인한 뒤 처리한다.

요청 상세는 승인 접수와 실행 결과를 구분한다. 접수된 요청이 실행 중이거나 완료돼도 같은 요청의 상세를 계속 확인할 수 있다. 승인 응답을 확인하지 못한 경우에는 상태를 다시 조회하며, 자동으로 승인을 반복하지 않는다. 관리자 로그아웃은 기존의 관리자 세션 종료 동작을 따른다.

명령 출력은 별도로 읽는다. 요청 기록이 남아 있어도 출력이 만료되거나 현재 연결에서 읽을 수 없을 수 있다. 출력 읽기 실패를 해결하려고 원 명령을 다시 실행하지 않는다.

## 서버 관리

서버를 명시적으로 선택한 다음 정책과 명령줄 도구를 관리한다. 작업 목록의 조회 서버와 정책 편집 서버는 서로 다른 상태다. 요청에서 해당 서버 정책으로 이동해도 원래 목록의 조회 조건은 바뀌지 않는다.

정책은 저장된 값, 수정 중인 초안, 검토 및 저장 결과를 구별한다. 다른 서버로 전환할 때 메모리 초안은 서버별로 유지하지만 페이지를 새로고침하거나 닫으면 사라진다. 인증 정보나 정책 초안을 브라우저 영구 저장소에 저장하지 않는다.

TEST 설정이 실제 적용 중이면 위험 심사와 개별 승인을 생략한다. 아래에 보이는 개별 허용값은 보존되며 TEST를 해제하면 다시 적용된다. TEST는 서버 계정 권한이나 파일 전송 경계를 확대하는 옵션이 아니다. 저장하지 않은 TEST 초안과 현재 저장된 TEST 효과를 구별해야 한다.

오래된 정책 제거를 포함한 제출에서는 현재 편집 서버뿐 아니라 함께 변경되는 정책도 검토한다. 저장 결과가 불명확하거나 연결 설정이 달라졌다면 먼저 현재 상태를 조회한다.

명령줄 도구의 설치, 로그인 상태 확인, 기존 요청 조회는 선택한 서버에서 수행한다. 서버 전환이 거절되면 표시된 현재 서버를 확인하고 진행 중이거나 확인이 필요한 작업을 먼저 처리한다.

## 처리 이력

기간은 요청 생성 시각을 기준으로 한다. 시작일과 종료일은 브라우저 현지 날짜이며 종료일도 포함한다. 기간 검색은 현재 큐만 좁히는 동작과 구별해, 기존에 보관된 명령 기록을 조회한다.

일반 요청 목록, 영속 명령 기록, 명령줄 도구 기록, 저장 출력은 보관 범위가 서로 다르다. 파일 전송은 현재 큐에 남은 범위만 제공할 수 있다. 장부에 보관되지 않았던 과거 자료를 복구하거나 보관 기간을 늘리는 기능은 아니다. 자동승인 통계의 최근 24시간 집계도 이력 조회 기간과 별개다.

이력 페이지는 제한된 분량을 차례로 읽는다. 페이지 사이에 상태가 바뀌거나 자료가 정리될 수 있으며, 전체 시점 고정 사본을 뜻하지 않는다. 새 조회로 최신 상태를 확인한다. 표시된 행 수를 전체 누적 요청 수로 해석하지 않는다.

## 중계기와 화면 설정

중계기 환경과 서비스 재시작은 등록된 모든 서버에 영향을 줄 수 있다. 서버 정책 저장과 중계기 환경 저장은 별개다. 환경 파일 저장 뒤에는 재시작해야 적용되는 항목이 있으며, 저장 완료와 재시작 결과를 각각 확인한다.

화면 설정의 표시 언어는 이 브라우저에만 저장한다. 언어 변경으로 새로고침하기 전에 저장하지 않은 초안과 확인이 필요한 작업을 처리한다. 명령·출력 원문이나 서버 정책의 언어는 변경하지 않는다.
