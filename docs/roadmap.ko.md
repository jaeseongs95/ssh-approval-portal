# 후속 작업과 고도화

기능 기준은 **v1.6.0**입니다. 서버별 실제 배포·보존 결과는 공개 릴리스의 `VALIDATION.json`에서 확인합니다. 구현·로컬 검사·실제 서버와 클라이언트 검증을 구분합니다. 테스트 확인 후 별도 요청에 따라 운영에 반영하며, 미관측 환경을 완료로 세지 않습니다.

## 완료한 작업

| 항목 | v1.5.0까지 반영한 내용 |
| --- | --- |
| 다운로드 | 서버 준비·기기 저장·에이전트 수신 구분, 카드·로그인 브라우저 저장 경로, 대상별 자동승인 |
| 요청 현황 | 현재 보관 중 요청의 상태별 합계와 범위 표시. SSH 접속 상태·전체 누적 건수와 구분 |
| 승인 이력 | 전체 너비에서 최신순 20개씩 표시하고 펼친 요청·출력 상태 유지 |
| 설정 화면 | 별도 `/settings`와 설정 탭. 업로드·다운로드·sudo·모델 자동승인 중요 선택 상시 표시 |
| 명령 관리 | 왼쪽 명령 그리드·검색·필터·스크롤·고정 헤더와 오른쪽 상세 편집 |
| 명령 자동승인 | 전체 명령줄의 명령이 모두 사전등록됐을 때 bypass. 미등록 명령이 하나라도 있으면 전체 평가. sudo는 별도 허용 |
| Jev 관측·설명 | 최근 24시간 실행 심사 집계, 한국어 표시 설명과 영어 평가 문맥 분리 |
| 저장 출력 읽기 | 명령을 재실행하지 않고 저장된 결과를 명시적으로 읽는 도구 |
| 시크릿 CLI | 심볼릭 링크 설치 경로의 입력 도구 실행 문제 수정 |
| ENV·재시작 | 지원 항목 편집·백업·충돌 확인·재시작·실패 복구. 테스트에서 실제 저장·재시작·원복 검증, 운영·AI Research는 기존 ENV 보존 |

다운로드 완료는 서버 파일 준비를 뜻하며 모든 클라이언트의 최종 저장·수신을 검증했다는 뜻은 아닙니다. 사용자 승인 후 모델 보류를 오판으로 집계하지 않으며 토큰 수를 청구금액이나 모델 효능으로 바꾸지 않습니다.

2026-10-18 TEST v1.6.0에 반영했습니다. 서버 검사·보존 검사와 실제 관리자 화면에서 언어 적용·복원, 이력 검색·필터·출력·탭 상태 유지, 7가지 화면 크기의 배치와 명령 목록 스크롤을 확인했습니다. 운영·AI Research의 배포·보존 확인 결과는 해당 공개 릴리스의 검증 자료에 기록합니다.

## 로컬 후속 수정

**다운로드 응답의 페이지 결속:** 이력에서 파일 저장을 요청한 뒤 설정을 거쳐 이력으로 돌아와도 이전 응답이 화면을 이동시키거나 새 안내를 덮어쓰지 않도록 했습니다. 링크 이동·브라우저 뒤로가기·현재 페이지 유지와 성공/오류를 조합한 6개 사례를 추가했습니다. 같은 테스트로 이전 결함과 수정본을 구별했고 Chromium·Firefox·WebKit 각 114개 화면·스크롤 회귀가 통과했습니다. Windows Node 회귀는 258개 통과, POSIX 전용 15개 제외이며 실제 서버·기기 저장 검증과 구분합니다.

## 남은 장기 고도화

1. **설치 자동화 — 네이티브 CLI 로컬 검증 완료:** [통합 CLI](install-workflow.ko.md)의 단위 검사 10개, Ubuntu 24.04 새 설치·갱신과 Ubuntu 22.04 새 설치의 실제 SSH·재설치·롤백·시작 실패 복구가 통과했습니다. 비기본 정책·완료 요청·저장 출력 보존과 독립 감사도 확인했습니다. 외부 DNS·터널·OAuth 등록, 대화형 연결 설정과 실제 로그인은 별도입니다.
2. **공급자 독립 — 로컬 HTTPS·토큰 검증 완료:** [Cloudflare 없는 HTTPS·토큰 경로](non-cloudflare-https.ko.md)의 설치·승인·실제 SSH·전송과 인증/TLS 실패 거부를 Ubuntu 24.04·22.04 격리 환경에서 확인했습니다. 공개 CA·DNS·실제 SSO 로그인은 별도입니다.
3. **AIK·AGS 실제 통합 — 상위 계약 대기:** AI-Kubernetes `07ebe7242e97ec13316cdbb017a0408a3b0775fe`의 공개 계약을 읽기 전용으로 확인했습니다. runtime integration 미인증과 AGS 2.9.0 host integration manifest 부재가 남아 있습니다. 권한·작업·실행·결과의 실제 연결은 미완료이며 합성 fixture로 대체하지 않습니다.
4. **여러 서버 통합 관리자 — 로컬 구현·검증 완료:** [다중 대상 관리자](multi-targets.ko.md)는 기존 한 중계기의 등록 대상을 활용합니다. 요청 조회·정책 편집·전체 ENV 범위, 명시적 정책 이동, 서버별 초안, 비활성 정책 보존, 조회 경합·언어 변경 보호를 확인했습니다. Chromium·Firefox·WebKit 각 108개 검사와 Ubuntu 24.04의 Node 270개·Python 34개 검사, 실제 SSH·전송·보존·복구 및 독립 감사를 통과했습니다. 별도 설치된 시험·운영·Research 중계기의 federation은 포함하지 않습니다.
5. **모바일 실기기 — 사용자 요청으로 제외:** iOS·Android 실제 기기와 모바일 Safari 터치 검증은 이번 범위에 포함하지 않습니다. Playwright의 화면 크기·키보드·스크롤 검사와 구분합니다.
6. **플랫폼별 파일 전달:** ChatGPT·Claude의 실제 입력·수신과 계정별 제약을 확인합니다. 불투명 ID를 주소로 꾸미거나 인증을 우회하지 않습니다.
7. **외부 시크릿 저장소 — 로컬 통합 검사 통과:** 기존 시크릿 포트에 읽기 전용 Vault KV v2를 연결했습니다. 토큰은 기존 숨김 입력 CLI와 local-file 저장소로 관리합니다. amd64·ARM64 에뮬레이션에서 각 Node 273개·Python 설정 6개와 실제 TLS·최소 읽기 권한·키 교체·삭제·destroy·토큰 취소 후 재시작을 확인했습니다. 키는 서비스 시작 시 읽으며 실행 중 캐시와 모델 발급처의 키 폐기는 별개입니다. 모델 요청의 키 전달은 로컬 응답 fixture로 확인했고, 실제 Jev 계정 인증·모델 품질과 물리 ARM은 검증하지 않았습니다. 원문은 채팅·도구 인자·출력·로그·패키지에 넣지 않습니다.
8. **ARM64·Docker — amd64·ARM64 에뮬레이션 로컬 검사 통과:** Docker Desktop의 Linux VM에서 amd64의 non-root·읽기 전용 루트·cap-drop·no-new-privileges 런타임과 실제 SSH·64 MiB 전송·재시작을 확인했습니다. Compose의 호환 가능한 v1.5.0 소스 이미지에서 현재 후보로 갱신·롤백·재갱신하고, 포트 변경·반복 갱신·의도적인 시작 실패 복구까지 통과했습니다. 비기본 정책과 기존 완료 요청 3개·저장 출력 3개, SSH 설정과 시크릿을 보존했습니다. 테스트 드라이버의 현재 버전 패키지 선택과 실패 로그 수집도 보강했습니다. 테스트 제어기만 Docker 소켓을 사용하며 서비스 컨테이너에는 부여하지 않습니다.

   ARM64는 x86_64 호스트의 Docker Desktop Linux VM에서 사용자 공간을 에뮬레이션한 결과입니다. 이미지와 실제 Node 프로세스가 arm64인 것을 확인했습니다. Ubuntu 24.04·22.04에서 통합 CLI의 빈 환경 새 설치와 호환 v1.5.0 기준 갱신을 각각 실행했습니다. 네 사례 모두 각 Node 270개·Python 34개 검사와 실제 SSH·64 MiB 파일 왕복, 재설치·롤백·시작 실패 복구·기존 데이터 보존을 통과했습니다. 기준 버전 갱신은 명시적인 v1.5.0 복귀와 현재 후보 재갱신도 확인했습니다. 기존 설치 도구의 두 Ubuntu 버전 갱신, 제한 런타임과 Compose 복구 검사도 통과했습니다. 실제 Ubuntu 호스트의 Docker 운영 환경, 외부 DNS·SSO와 물리 ARM 하드웨어는 별도 검증이 필요합니다.

서버 반영 시 직전 ENV·정책·키·기존 요청·전송·출력을 보존하며 특정 임계값이나 활성화 값을 강제하지 않습니다.
