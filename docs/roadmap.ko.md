# 후속 작업과 고도화

기준 릴리스는 v1.2.0이다. 후속을 개발·검증·서버 반영한 뒤 고도화를 순서대로 진행한다. 코드, 로컬 검증, 실제 서버·클라이언트 검증을 구분하며 미관측 환경을 완료로 세지 않는다.

## 우선 반영할 후속

| 항목 | 완료를 확인할 근거 |
| --- | --- |
| 다운로드 전달 | 서버 준비·사용자 저장·에이전트 수신을 구분하고 카드와 로그인 브라우저에서 실제 파일 크기·해시를 대조 |
| 다운로드 자동승인 | 사용자 검토·OK에 결합한 대상별 선택, 기본 OFF, sudo 설정 결합, 철회·경합·자동 재시도 금지 검사 |
| 긴 승인 이력 | 전체 너비에서 20개씩 표시, 최신 순서·필터·열린 요청·출력 상태 유지, 모바일 넘침 없음 |
| 요청 현황 | 보관 중 요청의 상태별 합계와 갱신 범위 명시; 모델 평가·실행, 누적 통계·연결 상태를 구분 |
| 별도 설정 페이지 | `/settings` 직접 진입·앞뒤 이동·인증 경계, 토큰 저장 금지, 승인 페이지의 중요 설정 표시 |
| Jev 관측 | 최근 24시간 실행 심사에서 사전명령/모델 자동승인·사용자 승인·호출·토큰·누락 범위를 실제 기록과 대조 |

사용자 승인 후 모델 보류를 오판으로 집계하지 않는다. 청구금액이나 실제 안전 정답은 현재 기록만으로 알 수 없으며 토큰 수를 청구금액·모델 효능으로 바꾸지 않는다. 등록 전 평가·파일 전송·별도 read 호출은 실행 심사 관측에서 제외한다.

## 순차 고도화

1. **설치 자동화:** 기존 설치·갱신·복구 스크립트를 재사용해 연결·정책·검증을 한 진입점으로 조립한다. dry run, 기존 설정 보존, 중복 생성 방지, 실패 복구와 실제 설치 증거가 필요하다.
2. **공급자 독립:** Cloudflare 외 HTTPS·인증 경로를 실제 설치·승인·명령·전송으로 검증한다. 공급자 장애가 인증 생략으로 이어져서는 안 된다.
3. **AIK·AGS 통합:** 이미 있는 연결 포트에 실제 제품을 붙여 권한·작업·실행·결과를 결합하고 적합성 시험을 마련한다. 합성 fixture는 실제 연동 인증을 대신하지 않는다.
4. **관리자 통합:** 기존 멀티서버 기반으로 시험·운영 관리 구성을 마련하고 서버 이름·선택 대상·승인 대상을 구분한다.
5. **모바일 지원:** iOS·Android의 실제 지원 앱에서 도구 호출·승인·파일 선택·전송·최종 저장을 확인한다. 모바일 화면 크기 시험과 실제 앱 검증을 구분한다.
6. **플랫폼별 파일 전달:** ChatGPT·Claude의 실제 입력·수신 기능과 계정별 제약을 확인한다. 불투명 ID를 다운로드 주소로 꾸미거나 인증을 우회하지 않는다.
7. **시크릿 공급자 확장:** 기본 로컬 저장소 이후 필요한 외부 저장소와 교체·폐기 수명주기를 검증한다. 원문은 채팅·도구 인자·출력·로그·패키지에 넣지 않는다.
8. **ARM64·Docker:** 실제 설치·재설치·업데이트·복구·전송·런타임을 검증하고 에뮬레이션과 실제 하드웨어를 구분한다.

테스트 서버의 전체 회귀와 실제 동작 확인 후 운영으로 반영한다. 실제 직전 ENV·전체 정책·키·기존 요청·전송·출력을 보존하며 특정 임계값이나 활성화 값을 강제하지 않는다.
